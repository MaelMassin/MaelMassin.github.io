# Portfolio de Maël Massin

Bienvenue sur le dépôt de mon portfolio académique et professionnel ! 

Ce site web a été conçu pour présenter mon parcours, mes compétences et mes projets en tant qu'étudiant en **BUT Réseaux et Télécommunications (R&T)** à l'IUT de Béthune.

##  Présentation du site

Il s'agit d'un site web statique interactif, moderne et responsive, structuré pour mettre en valeur :
- **À propos** : Mon profil, mes objectifs et mon parcours.
- **Résumé (CV)** : Mes formations et mes expériences professionnelles.
- **Portfolio & Compétences** : Mes fiches de bilans d'Apprentissages Critiques (AC) détaillant ce que j'ai fait, comment, et ce que j'en ai appris.

##  Technologies utilisées

Ce projet ne nécessite aucun backend (pas de base de données ni de conteneur Docker). Il est développé avec les technologies web standards :
- **HTML5 & CSS3** : Structure et mise en forme esthétique (avec effets visuels 3D, animations dynamiques).
- **JavaScript (Vanilla)** : Interactivité de la page (animations de scroll, scripts de rendu 3D).
- **Bootstrap 5** : Framework CSS pour garantir une mise en page responsive et fluide sur tous les appareils.
- **Thème graphique** : Basé sur le template *Craftivo* par BootstrapMade, avec de lourdes personnalisations visuelles.

##  Hébergement et Accès

Le site est hébergé directement et gratuitement via **GitHub Pages**. Aucune installation n'est requise.
